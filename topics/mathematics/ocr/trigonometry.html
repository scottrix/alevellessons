Mathematics — Trigonometry

Exam board: OCR  |  Back to subjects

Board-Specific Note

Two Pure papers plus one Applied (Mechanics or Statistics options).

Learning Objectives

  • Use sine and cosine rules
  • Sketch trig graphs
  • Solve trig equations

Key Points

  • SOH CAH TOA
  • sin²θ + cos²θ = 1
  • Graph period and amplitude

Lesson Plan (50 minutes)

  1. Starter (5 min): Recall prior knowledge of trigonometry with quick questions.
  2. Teaching (15 min): Work through each of the learning objectives, explaining principles step by step.
  3. Key points review (5 min): Revisit the key points together, confirming understanding.
  4. Worked example (10 min): Model the example question: Solve sinθ = √3/2 for 0 ≤ θ < 2π. Solution: θ = π/3, 2π/3
  5. Practice (10 min): Students attempt the practice questions independently; circulate and support.
  6. Plenary (5 min): Review answers and address misconceptions.

Homework

  • Solve cosθ = −1/2
  • Sketch y = 2 sin x for 0≤x≤2π
  • Find a side using the sine rule

Assessment

Check practice answers against the model answer; use the built-in practice questions as formative assessment.
